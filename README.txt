# Assembly Expansion

Welcome to the official repository for **Assembly Expansion**, a Minecraft mod developed by **kirsan122**. This project serves as a key piece of my personal portfolio (Pet-project) to demonstrate my practical programming and software architecture skills.

## 🎯 Project Purpose
I started this project to show future employers and admissions committees that I can write clean code, work with complex game APIs, and see a technical task through to completion. It is a major bonus to my resume, proving my technical background.

## 🚀 Grand Plans & High Ambitions (What I Want to Add)
I have huge plans for Assembly Expansion, focusing on advanced tech, energy, and chemistry, including:
* Nuclear Reactors
* Antimatter mechanics
* Particle Accelerators
* Complex Oil Refining systems

## ⚠️ Current Status & Hard Truths
* **The "No-Plan" Trap:** To be completely honest, when I first started, I didn't fully plan the long-term roadmap. I jumped straight into the code. Right now, none of the big features listed above are implemented yet. I am taking a step back to figure out how to code them properly.
* **The Texture Bottleneck:** I face a major challenge with art. Making textures takes a massive amount of time and effort for me, which is why every single new block takes ages to be added to the game.
* **Slower Development:** Progress is slow because high school takes up most of my time and energy right now. School is my top priority.

## 🔢 Versioning System (How to track my progress)
I use a strict versioning format for my releases on Modrinth/GitHub:
* **0.0.X** (e.g., 0.0.1) — **Alpha versions.** Extremely early stages, testing basic code, mostly empty.
* **0.X.0** (e.g., 0.1.0) — **Beta versions.** Core mechanics are working, adding main features.
* **X.0.0** (e.g., 1.0.0) — **Official Releases.** Stable, playable content.
